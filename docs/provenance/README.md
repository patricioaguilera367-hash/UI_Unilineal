# Provenance

Toda regla normativa o gráfica derivada del RIC deberá registrar su
procedencia.

Clasificaciones previstas:

- RIC18_EXPLICIT
- RIC18_CATALOG
- RIC18_REFERENCE
- APP_CONVENTION

No se incorporarán como requisitos RIC decisiones geométricas,
estéticas o de layout que no estén explícitamente respaldadas por la
fuente normativa correspondiente.
